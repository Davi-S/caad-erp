# Specification: Analytics Dashboard Sheet for Master Excel Workbook

## 1. Overview & Objectives

Currently, `master_workbook.xlsx` generated by `setup_excel.py` stores raw data across three sheets: `Products`, `Salesmen`, and `TransactionLog`. Business users opening the workbook in Excel or LibreOffice must write their own formulas or rely on backend CLI reports to view financial metrics and inventory levels.

This feature adds a dedicated **"Dashboard"** worksheet as the first tab in `master_workbook.xlsx`. The Dashboard leverages native, dynamic Excel formulas and native Excel charts so that whenever raw rows are added or updated in `TransactionLog`, `Products`, or `Salesmen`, all summary metrics and charts recalculate and update automatically in Excel.

---

## 2. Workbook Architecture & Sheet Ordering

The `Dashboard` sheet will be inserted as the **first worksheet (Index 0)** in the workbook and set as `workbook.active`.

**Target Sheet Order:**
1. `Dashboard` *(New - Active Sheet)*
2. `Products`
3. `Salesmen`
4. `TransactionLog`

---

## 3. Dashboard Layout & Visual Structure

The Dashboard is designed into structured grid sections containing summary KPI cards, data tables, and native Excel charts (`openpyxl.chart`):

```
+---------------------------------------------------------------------------------------+
| CAAD ERP - FINANCIAL & INVENTORY DASHBOARD                                            |
+---------------------------------------------------------------------------------------+
| [ SECTION 1: EXECUTIVE KPIs ]            | [ SECTION 2: PAYMENT METHOD BREAKDOWN ]    |
| - Total Revenue                           | - Data Table (Cash, PIX, Credit, Other)   |
| - Total Expenses                          | - Donut/Pie Chart: "Revenue by Payment"   |
| - Net Profit                              |                                           |
| - Profit Margin %                         |                                           |
| - Outstanding Debts                       |                                           |
+---------------------------------------------------------------------------------------+
| [ SECTION 3: SALES LEADERBOARD ]                                                      |
| - Ranked Table: Rank | Salesman | Deals Closed | Total Revenue | % of Total           |
| - Horizontal Bar Chart: "Sales Rep Performance"                                       |
+---------------------------------------------------------------------------------------+
| [ SECTION 4: PRODUCT PERFORMANCE & INVENTORY ]                                        |
| - Table: ProductID | Product Name | Stock On Hand | Sales Revenue | Status Alert      |
+---------------------------------------------------------------------------------------+
```

## 4. Section Specifications & Formulas

### 4.1 Section 1: Executive KPI Cards (Cells B2:C7)

| Cell / Location | Metric Name | Excel Formula | Format | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **B2:C2** | Header | `CAAD ERP Executive Summary` | Bold Title | Section Header |
| **B3:C3** | **Total Revenue** | `=SUM(TransactionLog!H:H)` | Currency | Sum of all revenue recorded |
| **B4:C4** | **Total Costs / Expenses** | `=SUM(TransactionLog!I:I)` | Currency | Negative values represent cost |
| **B5:C5** | **Net Profit** | `=C3+C4` | Currency | Net Profit = Revenue + Cost |
| **B6:C6** | **Profit Margin %** | `=IFERROR((C3+C4)/C3, 0)` | Percentage (`0.0%`) | `IFERROR` prevents `#DIV/0!` |
| **B7:C7** | **Outstanding Debts** | `=SUMIF(TransactionLog!F:F, "OnCredit", TransactionLog!H:H) - SUMIF(TransactionLog!C:C, "CREDIT_PAYMENT", TransactionLog!H:H)` | Currency | Unpaid credit sale balances |

---

### 4.2 Section 2: Payment Method Breakdown & Donut Chart (Cells E2:H7)

#### Data Table (E2:G7)
| Cell / Row | Payment Type | Revenue Formula | Share % Formula |
| :--- | :--- | :--- | :--- |
| **E3:G3** | `Cash` | `=SUMIFS(TransactionLog!H:H, TransactionLog!F:F, "Cash", TransactionLog!C:C, "SALE")` | `=IFERROR(F3/$C$3, 0)` |
| **E4:G4** | `PIX` | `=SUMIFS(TransactionLog!H:H, TransactionLog!F:F, "PIX", TransactionLog!C:C, "SALE")` | `=IFERROR(F4/$C$3, 0)` |
| **E5:G5** | `OnCredit` | `=SUMIFS(TransactionLog!H:H, TransactionLog!F:F, "OnCredit", TransactionLog!C:C, "SALE")` | `=IFERROR(F5/$C$3, 0)` |
| **E6:G6** | `Other` | `=SUMIFS(TransactionLog!H:H, TransactionLog!F:F, "Other", TransactionLog!C:C, "SALE")` | `=IFERROR(F6/$C$3, 0)` |

#### Visual Chart (Native Openpyxl `DoughnutChart`)
- **Chart Type**: `openpyxl.chart.DoughnutChart`
- **Title**: *"Revenue Distribution by Payment Method"*
- **Data Source**: `F3:F6` (Revenue values)
- **Categories**: `E3:E6` (Payment Type labels)
- **Position**: Embedded at cell `I2`.

---

### 4.3 Section 3: Sales Leaderboard & Performance Chart (Rows 10–16)

#### Ranked Leaderboard Table (A10:E15+)
| Column | Header | Excel Formula per Row $k$ (Salesman $k$) | Format |
| :--- | :--- | :--- | :--- |
| **A** | `Rank` | `=RANK(D{k}, $D$11:$D$20)` | Integer |
| **B** | `Salesman Name` | `=Salesmen!B{k}` | Text |
| **C** | `Deals Closed` | `=COUNTIFS(TransactionLog!E:E, Salesmen!A{k}, TransactionLog!C:C, "SALE")` | Integer |
| **D** | `Total Revenue` | `=SUMIFS(TransactionLog!H:H, TransactionLog!E:E, Salesmen!A{k}, TransactionLog!C:C, "SALE")` | Currency |
| **E** | `% of Total` | `=IFERROR(D{k} / $C$3, 0)` | Percentage (`0.0%`) |

#### Visual Chart (Native Openpyxl `BarChart`)
- **Chart Type**: `openpyxl.chart.BarChart` (Horizontal bars, `type="bar"`)
- **Title**: *"Sales Rep Revenue Ranking"*
- **Data Source**: `D11:D15` (Revenue per Salesman)
- **Categories**: `B11:B15` (Salesman Names)
- **Position**: Embedded at cell `G10`.

---

### 4.4 Section 4: Product Performance & Inventory Table (Rows 18+)

Derives current stock on hand and sales performance per registered product.

| Column | Header | Excel Formula per Row $i$ | Format / Rule |
| :--- | :--- | :--- | :--- |
| **A** | `ProductID` | `=Products!A{i}` | Text |
| **B** | `ProductName` | `=Products!B{i}` | Text |
| **C** | `Stock On Hand` | `=SUMIF(TransactionLog!D:D, A{i}, TransactionLog!G:G)` | Integer |
| **D** | `Total Sales Revenue` | `=SUMIFS(TransactionLog!H:H, TransactionLog!D:D, A{i}, TransactionLog!C:C, "SALE")` | Currency |
| **E** | `Stock Status Alert` | `=IF(C{i}<=0, "OUT OF STOCK", IF(C{i}<=5, "LOW STOCK", "OK"))` | Text Alert |

## 5. Implementation Details (`setup_excel.py`)

1. **Sheet Creation & Positioning**:
   ```python
   dashboard_ws = workbook.create_sheet(title="Dashboard", index=0)
   workbook.active = dashboard_ws
   ```
2. **Chart Generation**:
   Use `openpyxl.chart` primitives:
   - `DoughnutChart` for Payment Method breakdown.
   - `BarChart` for Salesman Leaderboard ranking.
3. **Styling & Presentation**:
   - Apply bold formatting to column headers and section titles.
   - Apply explicit number formatting (`#,##0.00` for currency, `0.0%` for percentages).
   - Auto-fit column widths for clear visual presentation.
